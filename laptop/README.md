# Компьютерное приложение

Простое приложение на Python/Tkinter для настройки ESP32 через USB Serial.
Форма настроек строится по корневому `config.json`, поэтому при добавлении полей
`int32`, `bool` или `string` вручную менять интерфейс не требуется.

## Запуск

Из корня репозитория:

```powershell
python -m pip install -r laptop/requirements.txt
python laptop/app.py
```

Выберите COM-порт и нажмите **Подключить**. При переходе на вкладку
**Настройки** приложение отправляет `{"op":"get"}` и показывает актуальные
значения с ESP32. Кнопка **Записать** проверяет значения и отправляет весь конфиг
одним запросом `set`.

ESP32 работает на скорости 115200 бод. JSON-команды и ответы передаются внутри
двоичных кадров с длиной и CRC32; формат подробно описан в корневом `README.md`.
Сейчас приложение реализует только пакеты типов 0 и 1 для чтения и записи
настроек. Остальные типы зарезервированы.
