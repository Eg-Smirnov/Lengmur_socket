# ESP32: настройки по USB Serial

Код платы находится в `esp/`: `esp.ino` содержит `setup()` и `loop()`, а `protocol.cpp` и `protocol.h` — обмен по Serial и работу с настройками. Папка `laptop/` предназначена для компьютерной части. Профиль сборки в `esp/sketch.yaml` закрепляет **ESP32 core 3.3.11** и **ArduinoJson 7.4.3** для платы ESP32-WROOM-32 (`esp32:esp32:esp32`). Сборка без загрузки на плату: `arduino-cli compile --profile esp32_wroom_32 esp`. Используется USB-порт, который виден компьютеру как последовательный порт. Скорость: **115200 бод**.

Каждый запрос — один JSON-объект в отдельной строке, завершённой `\n` (подойдёт и `\r\n`). На каждый непустой запрос плата возвращает одну строку JSON. При открытии порта приветственное сообщение не отправляется. Максимальная длина строки запроса — 511 байт без символов конца строки.

Пока все три настройки — целые числа со знаком в диапазоне `int32_t`. По умолчанию они равны нулю. После успешной записи конфиг сохраняется в NVS и загружается при следующем запуске. Если сохранённого конфига нет или он повреждён, используются значения по умолчанию.

| Действие | Запрос | Ответ |
| --- | --- | --- |
| Записать весь конфиг | `{"op":"set","config":{"setting_1":1,"setting_2":2,"setting_3":3}}` | `{"ok":true}` |
| Записать одно поле | `{"op":"set","field":"setting_2","value":42}` | `{"ok":true}` |
| Прочитать поле | `{"op":"get","field":"setting_2"}` | `{"ok":true,"field":"setting_2","value":42}` |
| Прочитать весь конфиг | `{"op":"get"}` | `{"ok":true,"config":{"setting_1":1,"setting_2":42,"setting_3":3}}` |

Полная запись требует ровно трёх известных полей. Некорректный запрос возвращает `{"ok":false,"error":"..."}`; возможные коды: `invalid_json`, `invalid_operation`, `invalid_config`, `invalid_field_or_value`, `unknown_field`, `storage_error`, `line_too_long`. При ошибке проверки или записи рабочие значения не меняются.

Список полей, типы и значения по умолчанию задаются в корневом `config.json`. Этот файл может читать и компьютерная программа. Поддерживаются типы `int32`, `bool` и `string`. После изменения схемы выполните `python tools/generate_config.py`, затем `arduino-cli compile --profile esp32_wroom_32 esp`. Сгенерированный `esp/config_generated.h` нужно сохранить вместе с изменённым `config.json`. Если конфиг заметно вырастет, увеличьте лимит входной строки. Сохранённый в NVS конфиг с устаревшим набором полей не загружается; используются новые значения по умолчанию.
