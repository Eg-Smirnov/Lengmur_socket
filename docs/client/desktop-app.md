# Клиентское приложение

Python-клиент на Tkinter больше не поддерживается. Его исходный код и файл
зависимостей сохранены в `laptop/python/` только как архив предыдущей реализации;
исправления и новые функции туда не добавляются.

Ведётся переход на приложение LabVIEW в `laptop/labview/`. Перед изменениями в
этой папке агенты должны прочитать локальный
[`README.md`](../../laptop/labview/README.md), где размещаются рабочие правила и
договорённости по проекту. Сейчас этот файл создан пустым.

Новый клиент должен обмениваться с ESP32 по Serial-протоколу, описанному в
[документе транспорта](../protocols/serial.md) и
[описании команд](../protocols/commands.md).
