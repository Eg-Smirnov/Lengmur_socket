# Компьютерное приложение

Приложение на Python/Tkinter настраивает ESP32 через USB Serial.

## Установка и запуск

Из корня репозитория:

```powershell
python -m pip install -r laptop/requirements.txt
python laptop/app.py
```

Выберите COM-порт и нажмите **Подключить**. После подключения приложение
отправляет `{"op":"get"}` и показывает актуальные значения с ESP32. Кнопка
**Записать** проверяет значения и отправляет всю конфигурацию одним запросом
`set`.

Форма строится по корневому [`config.json`](../../config.json). Для обычных
полей `int32`, `bool` и `string` вручную менять форму не требуется. Поле
`shunt_res` отображается как выбор автоматического режима или одного из шести
фиксированных сопротивлений.

При записи настроек выбранное значение `shunt_res` сразу применяется драйвером
ADG5408.

Клиент допускает только один незавершённый запрос. Пока он ожидает ответ или
тайм-аут, остальные действия интерфейса отключены. Размер JSON-запроса ограничен
256 байтами, а предел принимаемого двоичного кадра составляет 2048 байт.

ESP32 работает на скорости 115200 бод. Приложение поддерживает команды типа 0 и
ответы типа 1. Описание двоичного кадра находится в
[документе Serial-транспорта](../protocols/serial.md), а JSON-команд — в
[описании команд](../protocols/commands.md).
