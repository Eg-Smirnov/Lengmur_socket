# Клиентское приложение

Python-клиент на Tkinter больше не поддерживается. Его исходный код и файл
зависимостей сохранены в `laptop/python/` только как архив предыдущей реализации;
исправления и новые функции туда не добавляются.

Ведётся переход на приложение-библиотеку LabVIEW в `laptop/labview/`. Рабочие
правила разработки находятся в локальном
[`README.md`](../../laptop/labview/README.md), а документация по контрактам VI,
кодированию кадров и ошибкам — в
[документации клиента LabVIEW](labview/README.md).

Новый клиент должен обмениваться с ESP32 по Serial-протоколу, описанному в
[документе транспорта](../protocols/serial.md) и
[описании команд](../protocols/commands.md). Текущий проект LabVIEW включает
обёртки транспорта и кодировщик Serial-кадра; полный пользовательский API ещё
разрабатывается. Ethernet TCP пока возвращает ошибку «не реализован».
