# Клиентская библиотека LabVIEW

Клиент разрабатывается как библиотека LabVIEW 2015 (15.0), 64-bit, в проекте
[`Lengmur_socket.lvproj`](../../../laptop/labview/Lengmur_socket.lvproj) и
библиотеке [`Lengmur_socket.lvlib`](../../../laptop/labview/Lengmur_socket.lvlib).
Здесь описаны контракты созданных VI. Рабочие правила для агентов находятся в
[`laptop/labview/README.md`](../../../laptop/labview/README.md).

## Документы

- [Кодирование кадра](frame-encoding.md) — контракт `Encode Frame.vi`, ограничения
  и контрольные примеры.
- [Ошибки](error-handling.md) — error cluster, порядок распространения ошибок и
  коды клиентской библиотеки.

## Общая документация проекта

- [Архитектура прошивки](../../firmware/architecture.md) — активный транспорт,
  границы компонентов и обработка запросов.
- [Формат Serial-кадра](../../protocols/serial.md) — поля кадра, типы, предел
  payload и параметры CRC-32.
- [Команды и ответы](../../protocols/commands.md) — JSON-команды, порядок обмена
  и ошибки прошивки.
- [Обзор клиентского приложения](../desktop-app.md) — статус перехода с
  неподдерживаемого Python-клиента.
- [Сборка и разработка](../../development/build.md) — общие инструкции проекта.

Параметры протокола не следует независимо переопределять в документации клиента:
при изменении протокола сначала обновляется соответствующий документ в
`docs/protocols/`, затем здесь описывается реализация LabVIEW.
