# Аппаратная часть

Устройство построено на ESP32-WROOM-32. Микроконтроллер управляет двумя АЦП
AD7322BRUZ, мультиплексором шунтов ADG5408BRUZ, выходным силовым трактом и
Ethernet PHY KSZ8081RNACA-TR. Текущий интерфейс связи с компьютером — USB
Serial через CP2102-GMR; Ethernet ещё не используется прошивкой.

## Функциональные группы

- Измерение напряжения: отдельный AD7322 на шине `USPI_*`.
- Измерение тока: второй AD7322 на шине `ISPI_*`.
- Выбор диапазона тока: ADG5408 и линии `RES_SEL_0`…`RES_SEL_2`.
- Ethernet RMII: KSZ8081, линии данных RMII, MDIO/MDC и `ETH_RST`.
- USB UART и загрузка: `USB_UART_TXD`, `USB_UART_RXD`, `ESP32_IO0`, `ESP32_EN`.
- Управление силовым трактом: `OUT_EN`; прикладное управление этой линией будет
  реализовано отдельно, текущая прошивка её не инициализирует.
