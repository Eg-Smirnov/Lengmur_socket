# Документация Lengmur Socket

Документация разделена по областям проекта. Неподтверждённые характеристики и
аппаратные ограничения явно отмечены в соответствующих документах.

## Аппаратная часть

- [Обзор устройства](hardware/overview.md) — функциональные узлы и их связи.
- [Распиновка ESP32-WROOM-32](hardware/pinout.md) — выводы модуля и назначение GPIO.
- [Ethernet PHY KSZ8081](hardware/ethernet.md) — RMII, тактирование и открытые вопросы.
- [Аналоговый тракт](hardware/analog-front-end.md) — AD7322, делитель напряжения и выбор шунта ADG5408.

## Прошивка

- [Архитектура](firmware/architecture.md) — транспорт, кодек кадров, общая очередь и диспетчер приложения.
- [Конфигурация](firmware/configuration.md) — общая схема `config.json` и генерация заголовка.
- [Драйвер AD7322](firmware/drivers/ad7322.md) — настройка и чтение пары АЦП.
- [Драйвер ADG5408](firmware/drivers/adg5408.md) — программный выбор шунта.

## Протоколы

- [Serial-транспорт](protocols/serial.md) — двоичный кадр, CRC32 и восстановление синхронизации.
- [Команды и ответы](protocols/commands.md) — JSON-команды конфигурации и коды ошибок.
