# Конфигурация прошивки

Корневой файл [`config.json`](../../config.json) является общей схемой настроек
для прошивки и компьютерного приложения. В нём перечислены имена полей, их типы
и значения по умолчанию.

Сейчас определены:

| Поле | Тип | Значение по умолчанию |
| --- | --- | --- |
| `sample_rate` | `int32` | `1000` |
| `min_voltage` | `int32` | `-10` |
| `max_voltage` | `int32` | `10` |
| `shunt_res` | `shunt_res` | `"auto"` |

Тип `shunt_res` принимает `"auto"` либо одно из фиксированных сопротивлений:
200, 1000, 10000, 100000, 1000000 или 10000000 Ом.

После изменения схемы нужно из корня репозитория выполнить:

```powershell
python tools/generate_config.py
```

Скрипт проверяет схему и обновляет
[`config_generated.h`](../../esp/src/application/configuration/config_generated.h).
Сгенерированный файл нельзя редактировать вручную; его следует сохранять в
репозитории вместе с изменённым `config.json`.

Компьютерное приложение строит форму настроек по `config.json`. Подробнее о
чтении и записи значений см. в [описании команд](../protocols/commands.md).
